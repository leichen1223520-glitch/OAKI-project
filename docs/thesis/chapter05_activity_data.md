# 第5章 多厂月度活动数据分析与碳绩效基准

> **数据标注**：本章基于 `[真实活动数据]`（深圳46厂月度数据）。
> 直接GHG排放（N₂O、CH₄）本章**不声称已验证**，采用`[仿真-Python-AAO]`默认值估算。

## 5.1 46厂数据集构建与质量分析

基于深圳市排水处提供的月度统计数据（T026完成），建立深圳46座污水处理厂2026年1-6月的规范化面板数据集。

**数据概要**：
- 记录：276条（46厂 × 6月）
- 空间范围：深圳市特区内及各区水质净化厂（厂名哈希脱敏）
- 时间范围：2026年1月-6月
- 变量：处理水量（万m³/月）、进出水COD/TN/NH₄⁺/TP/SS（mg/L）

**数据质量**：完整性100%（所有46厂6个月均有数据）。主要质量问题：少数厂出水水质数值接近检测限（如TP_out=0.05 mg/L重复出现，可能为检测限替代值）。

## 5.2 水厂绩效画像

### 5.2.1 规模分布

46厂设计规模从0.05万m³/d（小型厂）到30万m³/d（滨河水质净化厂）。按规模分类：
- 小型（<1万m³/d）：~30%
- 中型（1-5万m³/d）：~40%
- 大型（>5万m³/d）：~30%

### 5.2.2 进水水质特征

深圳46厂进水水质呈现以下规律（2026年1-6月）：
- **COD_in**：均值268 mg/L，标准差81 mg/L；范围43-525 mg/L
- **TN_in**：均值38.2 mg/L，标准差9.3 mg/L
- **NH₄⁺_in/TN_in比**：均值0.73，反映深圳污水以氨氮为主要氮形态
- **COD/TN比**：均值6.8（范围1.5-14.9），大部分厂处于合理反硝化范围（>5）
- **季节变化**：6月（雨季高峰）进水浓度明显下降，Q增加约35%

### 5.2.3 出水水质达标情况

**COD_out**：均值11.7 mg/L，全部在一级A标准（50 mg/L）内
**NH₄⁺_out**：均值~0.3 mg/L，全部在一级A标准（5 mg/L）内
**TN_out**：均值6.7 mg/L，全部在一级A标准（15 mg/L）内
**TP_out**：均值~0.1 mg/L，全部在一级A标准（0.5 mg/L）内

## 5.3 活动数据层碳排放核算 `[真实活动数据]`

### 5.3.1 间接排放估算

基于T076-T077，使用`src/carbon/carbon_accounting.py`计算46厂碳排放强度：

**关键结果**（基于`results/tables/carbon_46plants_2026_v1.csv`）：
- 总碳排放强度（含估算直接排放）均值：**0.337 kgCO₂eq/m³**（范围：0.21-0.43）

### 5.3.3 不确定性

基于Monte Carlo（2000次采样）：
- 代表性水厂（400万m³/月）95%置信区间：**[0.187, 0.348] kgCO₂eq/m³**
- 变异系数（CoV）：15.6%
- **主要不确定性来源**：N₂O直接排放（因无实测，采用文献分布采样）+ 电网排放因子

## 5.4 本章小结与局限性

**主要结论（有真实数据支撑）**：
1. 深圳46厂间接排放（电力）占总碳排放强度约82%，电力是当前阶段可量化的主要减排目标
2. 进水水质呈明显季节性，6月雨季碳排放强度最低
3. 总碳排放强度与文献报道的中国污水处理行业平均值（0.3-0.4 kgCO₂eq/m³）基本一致

**局限性**（必须明确说明）：
1. **直接GHG排放未实测**：N₂O/CH₄贡献基于仿真默认值，误差可能达±50%以上
2. **能耗数据部分缺失**：部分厂能耗采用回归估算（`[估算-回归]`），精度约±15%
3. **月度分辨率**：月度数据无法反映日内、工况变化对碳排放的影响
4. **仅覆盖2026年上半年**：不包含完整年度季节周期

*结论边界：本章结论仅适用于活动数据层的间接排放分析，不涉及GHG直接排放的精确核算。*
