### 3.2.3 水质特征分析

深圳46厂进水水质呈现显著的季节性规律：
- **1-3月（旱季）**：进水COD平均~350 mg/L，COD/TN比~7.5，碳氮比较高，反硝化能力相对充足
- **4-6月（雨季）**：进水浓度明显下降（6月COD均值降至约200 mg/L），COD/TN比降至~5-6，部分厂面临碳源不足风险

这种季节性模式对N₂O排放有重要影响：碳氮比低的工况下，反硝化不完全可能导致N₂O累积（Ahn et al. 2010；文献证据）。

## 3.3 Python AAO仿真平台 `[仿真-Python-AAO]`

> ⚠️ **重要声明**：以下仿真结果由Python简化AAO动力学模型生成，非BSM2G MATLAB/Simulink输出。两者的核心差异见表3.X。当MATLAB/BSM2G可用时，应使用真实BSM2G输出替换本章数据。

### 3.3.1 仿真器设计原理

Python AAO近似仿真器（`src/simulation/aao_simulator.py`）采用以下设计：

**进水生成模块**：
- 日变化：双峰曲线（8:00和20:00峰值，±40%波动）
- 季节变化：夏季浓度偏低15%（稀释效应+降雨）
- 降雨事件：泊松过程，降雨频率12%，2.5倍流量冲击
- 随机噪声：5%幅度正态噪声

**出水计算模块**（向量化计算）：
- 硝化效率：Monod动力学 + Arrhenius温度修正 + SRT效应
- 反硝化：化学计量学 + 内回流比约束
- P去除：PAO简化代谢（EBPR近似）
- 能耗：O₂需求 + 鼓风机效率 + 泵能

**GHG估算模块（简化）**：
- N₂O：DO依赖型路径切换函数（Ni et al. 2011近似）
- CH₄：进水携带 + 好氧吹脱（Daelman et al. 2012近似）

### 3.3.3 Python仿真器与BSM2G的差异说明

| 对比维度 | BSM2G (目标) | Python近似仿真器 (当前) |
|---------|-------------|----------------------|
| 实现语言 | MATLAB/Simulink | Python (numpy/scipy) |
| 模型复杂度 | 完整ASM1扩展（15组分，8过程） | 简化代数近似 |
| 沉淀池模型 | 10层沉淀模型 | 无（简化处理） |
| N₂O模型 | 扩展AOB双路径 + 反硝化 | 简化路径切换函数 |
| 控制回路 | PI控制，实时仿真 | 固定DO设定点 |
| 数据验证 | 与BSM2G原文对比 | 未验证 |
| 结论适用性 | "BSM2G条件下验证" | **"Python近似仿真条件下验证"** |

**结论**：本阶段（阶段A）所有基于仿真数据的实验结论，仅适用于Python近似仿真条件，不等同于BSM2G仿真或真实AAO水厂条件。

## 3.4 数据治理规范

所有数据严格遵循`DATA_POLICY.md`中的分类规则：
- 原始真实数据：本地存储，不上传GitHub（植保于`data/raw/`，已在`.gitignore`排除）
- 处理后数据：以哈希ID代替真实厂名，保留统计特征
- 仿真数据：完整上传，含随机种子和配置文件
- 数据字典：`data/schema/data_dictionary.csv`

## 3.5 本章小结

本章建立了OAKI项目的多源数据体系：
1. **46厂月度面板** `[真实活动数据]`：276条记录，覆盖11项水质/水量变量，完整性100%，用于城市尺度间接排放基准。
2. **Python AAO仿真数据** `[仿真-Python-AAO]`：4个虚拟水厂，34,925个训练样本（VPlant_A），用于方法开发和消融实验。
3. **数据局限性**：本阶段（阶段A）无真实GHG直接测量数据；Python仿真器不等同于BSM2G。所有仿真数据标注明确，不用于声称真实GHG预测能力。
