## 二、研究问题逻辑完备性审查

### 2.1 中心科学问题分析

**任务书V1.0提出的中心问题**：
> 在GHG真值稀缺、运行数据标签不完整、不同污水厂运行条件存在域差异的情况下，如何融合机理仿真数据、ASM知识和多时间尺度运行数据，建立可迁移、可校准、可解释并能输出不确定性的AAO全厂碳排放模型？

**逻辑完备性评分**：✅ 问题表述清晰，研究动机充分

**三个子问题的递进关系**：
- RQ1（OAKI-PL）：无GHG标签数据能否帮助GHG预测 ✅ 独立
- RQ2（OAKI-Transfer）：机理先验如何迁移，控制负迁移 ✅ 依赖RQ1
- RQ3（OAKI-Cal/Carbon）：需要多少天真值完成可靠校准 ✅ 依赖RQ1+RQ2

**递进关系判断**：三个研究问题存在逻辑依赖关系，但各自独立性足够，满足博士论文要求。

## 五、BSM2G-ASM-机器学习-多任务-迁移-碳核算逻辑跳跃检查

### 5.1 逻辑链路图

```
BSM2G仿真数据
    ↓（提供完整GHG标签）
预训练多任务编码器（OAKI-PL）
    ↓（提供共享过程表示）
迁移到虚拟/真实目标厂（OAKI-Transfer）
    ↓（提供预测分布）
概率校准（若有真实GHG真值）
    ↓（提供GHG条件分布）
全厂碳核算（OAKI-Cal/Carbon）
    ↓
情景优化与Pareto分析
```

**问题5.1：BSM2G → 多任务学习的连接**

任务书说BSM2G提供"完整标签"，用于OAKI-PL预训练。但BSM2G模拟的是特定AAO构型（典型欧洲水质），与中国深圳AAO厂存在显著进水水质差异（C/N比、温度、COD组分）。

**建议**：在第3章明确"BSM2G作为机理知识源而非真实训练域"，并专门设计域差异分析实验（T048）以量化这种差距。

**问题5.2：ASM参数 → 机器学习核心的连接**

任务书提出"ASM约束混合核心"，但在阶段A没有真实小试数据时，ASM参数只能来自文献。用文献范围参数构造的"机理约束"实质上是带先验范围的正则化，而非真正的机理约束。

**建议**：在第6章明确区分：
- 阶段A：文献先验范围作为软约束（正则化）
- 阶段B：小试后验作为强约束

## 九、审查结论

**任务书V1.0总体评估**：研究问题有价值，方法路线在方向上合理，但存在以下关键问题：

1. **阶段A/B界限模糊**：需要将94项任务明确分为"立即可执行"和"依赖真实数据"两类。
2. **现有草稿与新框架断层**：现有8章FPCM草稿无法直接升级为9章OAKI框架，需要实质性重构。
3. **BSM2G是阶段A的关键阻塞项**：需要用户优先解决。
4. **证据边界管理是核心风险**：必须在每一章建立"声明可被什么数据支撑"的审查机制。

**建议**：按照《博士论文研究设计V2.0》重新组织任务，以阶段A能完成的内容为主线，阶段B内容明确标记为"后续增强"。
